# Сборка и выпуск маркированных наборов

Микросервисная архитектура складской системы для сборки наборов из маркированных товаров. Система хранит фактический состав набора, резервирует компоненты и отражает выпуск после подтверждения маркировки. Повторная доставка сообщений и восстановление после сбоя сохраняют исходный состав и не приводят к повторному списанию.
