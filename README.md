# Сборка и выпуск маркированных наборов

На складе из двух маркированных товаров собирают один набор. Система резервирует компоненты, выдаёт код набора и сохраняет коды товаров, которые в него вошли. Задание завершается после того, как сотрудник подтвердит сборку, система маркировки зарегистрирует состав, а складской учёт отразит расход компонентов и выпуск наборов.

За эти этапы отвечают три сервиса со своими базами данных. «Сборка» ведёт задание и хранит сканы, «Маркировка» получает коды и регистрирует состав, а «Складской учёт» ведёт остатки, резервы и движения. Сервисы обмениваются командами и событиями через RabbitMQ. Если ответ внешней системы потерялся, сервис сверяет исходную операцию по сохранённому идентификатору. Так процесс можно продолжить без второго документа или повторного списания.
